## What this test does

Chrome against the bench console (super admin). Stores → a store → Owners. 'Add an owner': the Name, Email and Password boxes start on the same line and have the same height (the Password hint 'for a new login' sits under its box and pushes nobody), the 'Add owner' button is level with the boxes, they sit side by side in order with real width. On a 520 px window they stack, no two overlap, nothing sticks out and the page doesn't scroll sideways. An owner's row keeps Reset password, Deactivate and Remove together on one line on the right, inside the row; 'Reset password' opens a password box with Set (disabled until 8 characters) and Cancel, and Cancel closes it.

- The Password hint must NOT push the other boxes out of line.
- No field may overlap another or stick out of the window.
- No errors in the browser.
