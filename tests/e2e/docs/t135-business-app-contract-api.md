## What this test does

A private API on an in-memory database with orders in two outlets, a coupon, a booking, dishes with counted stock, a rating, a bill and a target. The app signs in the way it does on the phone and calls each address with the request it really sends; each answer is checked against the field list written from the app's own types (names, types, nullable fields). Includes the case a phone run found: /api/outlets answers `_id`, not `id`. Writes are checked too (a bill, a person, a coupon switch, counted stock) and the four report file kinds (Excel, PDF, CSV, JSON) come back with the right content type and a .ext name.
