# T125 — A store's settings are kept per plan: leaving a plan saves them, coming back restores them (Custom → Pro → Custom), a plan it never had starts clean

**Run it alone:** `node run.mjs --only t125` (add `--visible` to watch it)

## What this test does

API checks on an in-memory database. A store on a Custom plan with limits set by hand (12 people, 7 outlets, 40 tables) and features unlocked (marketing, delivery) moves to Pro: the answer says the Custom settings were saved and Pro started clean; Pro's own limits apply and nothing of Custom carries over; the store's page lists Custom among the plans it has left with what it had. Months later it goes back to Custom: the answer says the settings were restored, and the old limits and features are exactly back. A plan it never had (Basic) starts clean, and Custom and Pro are both remembered. Settings sent with the change replace what was saved and are what is saved when it leaves again; changing only the settings on the same plan is not a plan change; 'No plan' is a plan too; an unknown plan is 400; a store owner is 403.

## Steps

1. A Custom plan with hand-set limits and unlocked features
2. It moves to Pro: the Custom settings are put away, Pro starts clean
3. Months later: back to Custom — the old settings come back by themselves
4. Another plan it never had starts clean, and the first one is still remembered
5. Settings sent with the change always win
6. 5b. The console sends the settings itself (already filled in from the saved ones): still counts as restored
7. Things that are not a plan change

## What to expect (these must happen)

- Leaving a plan saves the store's settings on it; coming back to that plan restores them exactly.
- A plan the store never had starts clean (the old plan's limits do not carry over).
- The answer says what happened (saved / restored / started clean) and the store's page lists the plans it has left.

## What must NOT happen

- Custom limits must NOT carry over onto Pro.
- Settings given with the change must NOT be overwritten by saved ones.
