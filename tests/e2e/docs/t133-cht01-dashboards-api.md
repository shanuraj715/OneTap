## What this test does

A private API on an in-memory database with orders in different order types. The platform dashboard's sales.monthlyChannels has 12 months that line up with the monthly bars; dine-in, takeaway, delivery and 'other' (any other order type) add up to each month's sales; a cancelled order is never counted. A store's dashboard revenueTrend still has 14 days and now carries each day's split; an unpaid order is left out; a day with no sales has an empty split.

## Steps

1. The platform dashboard: last 12 months, split by order type
2. A store's dashboard: last 14 days, split by order type

## What to expect (these must happen)

- The platform dashboard has twelve months of sales split into dine-in, takeaway, delivery and other.
- In every month and every day the layers add up to the same total as the bars.
- A store's 14-day trend carries each day's split by order type.

## What must NOT happen

- A cancelled order must NOT be in any layer.
- An unpaid order must NOT be in the store's daily trend.
- The layers must NOT add up to something different from the column chart.
