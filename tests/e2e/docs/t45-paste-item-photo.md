## What this test does

In Chrome as the owner of Acme Momos, on Menu → a dish → Edit (✎): the Photos box offers 'Add photo' AND 'Paste photo' and says 'Press Ctrl+V (⌘V on a Mac) here, or use Paste'. A real picture (drawn on a canvas and put on the browser's clipboard) is pasted with the keyboard shortcut — it uploads like a chosen file and appears as a new photo; a second picture with the 'Paste photo' button; a big 2400×1600 picture is pasted and saved as a smaller WebP; pasting with the cursor in the Name box adds the picture and leaves the name alone, while pasting TEXT into the Name box still pastes the text and adds no photo; pressing 'Paste photo' with only text on the clipboard says there is no picture; once the dish has six photos the 'Add'/'Paste' tiles go and a paste says the dish already has six. Saving keeps the pasted photos (server-made WebP files that open). The dish's own photos are put back at the end.

## Steps

1. Opening the dish editor
2. A copied picture is pasted with Ctrl/⌘+V
3. The 'Paste photo' button
4. Pasting while the cursor is in a text box
5. Nothing but text on the clipboard
6. Up to the sixth photo, then the limit
7. Saving the dish

## What to expect (these must happen)

- The Photos box has both 'Add photo' and 'Paste photo', and a line telling people they can press Ctrl+V / ⌘V.
- Ctrl/⌘+V with a picture on the clipboard adds it as a new photo (uploaded and compressed like any other); so does the 'Paste photo' button.
- A pasted picture works while the cursor is in a text box if the clipboard holds only a picture; pasting text into a text box still pastes the text and adds no photo.
- With no picture on the clipboard the button explains; at six photos a paste says the dish is full.
- After saving, the dish has the pasted photos as WebP files that open.

## What must NOT happen

- Pasting text must NOT add a photo or be swallowed.
- A paste must NOT add more than six photos to a dish.
- The browser must NOT log JavaScript errors.
